# BBPMS 项目需求（Requirements）

> 本文档描述 BBPMS 的系统目标、用户与角色、功能需求与非功能需求。适用于项目负责人、需求评审与验收。

## 1. 系统目标

构建一套覆盖宽带装维业务**全生命周期**的企业级管理平台，支撑从客户申请到装维完工归档的完整流程，并提供派单调度、考勤、请假等运营管理能力。

**核心业务价值**：流程线上化、派单自动化、过程可审计、质量可度量。

## 2. 用户与角色

| 角色 | 代码 | 权限范围 | 主要操作 |
|---|---|---|---|
| 超级管理员 | `SUPER_ADMIN` | 全部数据 + 全部菜单 | 系统配置、用户/角色/菜单/部门管理、强制关闭工单、明文客户信息 |
| 客服 | `CUSTOMER_SERVICE` | 本人数据（SELF） | 客户管理、创建订单、订单改约 |
| 审核员 | `AUDITOR` | 本人数据（SELF） | 订单审核 |
| 调度员 | `DISPATCHER` | 本人数据（SELF） | 派单看板、手动派单、改派、SLA 监控、请假审批 |
| 装维工程师 | `INSTALLER` | 本人数据（SELF） | H5：我的工单、接单/施工/完工、考勤签到、请假申请 |
| 客户 | `CUSTOMER` | 本人数据（SELF） | 查询自己的订单 |

数据范围（`sys_role.data_scope`）：`1=ALL`、`2=DEPT`、`3=DEPT_AND_CHILD`、`4=SELF`、`5=CUSTOM`。当前实现支持 `1/ALL` 与 `4/SELF`（DEPT/CUSTOM 需业务表具备 dept 列，见架构文档）。

## 3. 功能需求（按模块）

### 3.1 认证与权限（auth / user）
- F1. 登录 / 登出 / 刷新：RSA 加密密码 + 图形验证码 + JWT（access 30min，refresh 7d 单次旋转）。
- F2. 用户管理：用户 CRUD、分配角色、改密、启停用。
- F3. 角色 / 菜单 / 部门管理：RBAC（角色-菜单-权限码），菜单即权限点（DIR/MENU/BUTTON）。
- F4. 数据范围控制：按角色对列表查询注入行级 SQL 过滤。
- F5. 装维档案：技能标签、服务区域、当前位置、工作量、评分。

### 3.2 订单（order）
- F6. 客户管理：增改查 + 敏感字段（身份证/手机号）SM4 加密存储与脱敏展示。
- F7. 订单生命周期：创建 → 审核（通过/驳回）→ 派单 → 安装 → 完工 → 归档；含预约管理、时间线审计。

### 3.3 工单与 SLA（workorder）
- F8. 工单生命周期：创建 / 接单 / 开工 / 完工 / 转单 / 取消 / 停滞 / 恢复 / 改派 / 强关。
- F9. SLA 引擎：DISPATCHED 超时自动取消重派、IN_PROGRESS 无心跳置停滞、STALLED 超时自动取消重派；阈值可配置。
- F10. 心跳上报：H5 每 5 分钟上报，驱动 SLA 判定。

### 3.4 派单（dispatch）
- F11. 自动派单：4 因素加权评分（距离 40% / 负载 25% / 技能 20% / 评分 15%），排除请假装维，并发加锁。
- F12. 手动派单 / 改派：调度员人工指定；改派有冷却期。
- F13. 派单记录与统计：候选评分序列化存档，支持审计回溯。

### 3.5 装机（install）
- F14. 五步装机：到达现场 / 装机信息 / 现场照片（≥3）/ 电子签名 / 完工提交。
- F15. BSS 开通：完工后调运营商开通系统（生产对接，开发用 Mock，可配失败率压测补偿）。

### 3.6 考勤（attendance）
- F16. 签到 / 签出 / 休息；自动签出（默认 8h）；历史清理（默认 90d）。
- F17. 团队在岗看板、月度统计。

### 3.7 请假（leave）
- F18. 请假申请（含病假必传附件）、多级审批（阈值/病假升级 2 级）、撤销。
- F19. 联动：请假批准后自动取消并重派在派工单；派单排除请假装维。

### 3.8 支撑功能
- F20. 通知消息：短信 / 微信模板发送 + 发送记录（dev 用 Mock）。
- F21. 日志审计：操作日志（AOP 异步落库）、登录日志。
- F22. 文件管理：本地 / MinIO 存储，上传 / 预签名 / 按业务关联查询。
- F23. 监控：Spring Actuator（health / metrics）+ Knife4j 接口文档。

## 4. 非功能需求

| 类别 | 要求 |
|---|---|
| 性能 | 派单接口秒级返回；列表分页 ≤500 行/页；心跳上报 5min 间隔 |
| 可用性 | 单点单体，依赖 Docker Compose（MySQL + Redis）；可水平扩容实例（Redis 共享） |
| 安全 | JWT（RS256）+ BCrypt 密码；敏感字段 SM4 加密；RBAC 按钮级权限；行级数据范围 |
| 可靠性 | 本地事务保证一致性；事件驱动跨模块（AFTER_COMMIT 事务后）；乐观锁防并发覆盖 |
| 可维护性 | 按业务域分包（controller/service/mapper/entity/dto/vo/config）；单库 `bbpms` |
| 合规 | 身份证/手机号加密存储；操作留痕（operation_log / order_audit_log / work_order_timeline） |

## 5. 范围外 / 暂不实现

- 分布式事务（Seata）、消息队列（RabbitMQ）、配置中心（Nacos）、网关（Gateway）——均以进程内等价物替代。
- DEPT/CUSTOM 数据范围过滤（业务表缺 dept 列，属架构待办）。
- 真实短信 / 高德 / BSS 对接（需生产密钥，当前 Mock）。
