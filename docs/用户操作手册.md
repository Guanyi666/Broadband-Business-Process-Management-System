## 一、系统简介

**BBPMS（Broadband Business Process Management System）** 是面向宽带运营商的业务全流程管理系统，覆盖从客户报装到网络开通的完整链路：

```
客户申请 → 客服建单 → 审核员审核 → 系统自动派单 → 装维上门施工 → 网络开通 → 订单完成
```

系统包含**两大使用端**：

| 端 | 适用人群 | 访问方式 | 主要功能 |
|---|---|---|---|
| **管理后台** | 客服、审核员、调度员、管理员 | PC 浏览器 | 客户/订单/工单/资源/系统管理 |
| **装维端（H5）** | 装维工程师 | 手机浏览器 | 工单接单、上门装机、考勤请假 |

系统内共 **6 种角色**，每种角色登录后看到的菜单、可执行的操作都不同：

| 角色 | 职责 |
|---|---|
| 超级管理员（admin） | 系统全部功能 + 用户/角色/菜单/部门配置，可查看客户明文信息 |
| 客服（CS） | 客户建档、创建订单、驳回后修改重提 |
| 审核员（AUDITOR） | 订单审核（通过/驳回） |
| 调度员（DISPATCHER） | 派单工作台、手动派单、改派 |
| 装维工程师（INSTALLER） | 装维端接单施工、考勤、请假 |
| 客户（CUSTOMER） | （预留）查看自己的订单 |

> **权限说明**：系统对每个菜单和操作都有权限控制。菜单里看不到某项 = 你的角色无该权限，属正常现象，请联系管理员开通。

## 二、快速开始：登录与账号

### 2.1 访问地址

| 端 | 地址（默认本地部署） |
|---|---|
| 管理后台 | `http://localhost:5173` |
| 装维端 H5 | `http://localhost:9002` |
| 接口文档（开发用） | `http://localhost:8080/doc.html` |

### 2.2 登录步骤（管理后台）

1. 打开管理后台地址，进入登录页；
2. 输入**用户名**和**密码**；
3. 输入右侧**图形验证码**（看不清可点击图片刷新）；
4. 点击【登录】。

> 登录安全说明：密码提交前会加密传输，登录后会话自动维持（令牌约 30 分钟有效，过期自动续期），长时间未操作后需重新登录属正常现象。

### 2.3 默认账号（演示环境）

> 演示环境所有账号密码均为 **`admin123`**。正式环境请立即修改默认密码。

| 账号 | 角色 | 能做的事 |
|---|---|---|
| `admin` | 超级管理员 | 全部功能 + 查看明文客户信息 |
| `cs1` / `cs2` | 客服 | 客户管理、创建订单、驳回重提 |
| `audit1` | 审核员 | 订单审核、日志查看 |
| `disp1` | 调度员 | 派单工作台、自动/手动派单、改派 |
| `install1` ~ `install5` | 装维工程师 | 装维端全部功能 |

### 2.4 修改密码

登录后，点击右上角头像 → **个人中心** → 修改密码（需输入原密码）。

## 三、管理后台功能详解

登录后默认进入**数据看板**。左侧菜单即你的角色可用的全部功能。

### 3.1 数据看板

展示核心经营指标，实时刷新：

- **订单总量与状态分布**：各状态订单数量一目了然；
- **趋势与时效**：订单创建趋势、派单时长、SLA 工单时效预警；
- **人员概况**：在线装维数、值班人数、待审批请假等。

> 说明：看板各板块按权限显示。例如装维角色看不到"派单策略构成"板块，是因为该角色无对应权限，属正常设计，不影响其他板块。

### 3.2 客户管理

路径：**客户管理 → 客户列表**

- **查询客户**：输入姓名或手机号，点击搜索；
- **新增客户**：点击【新增】，填写姓名、手机号、证件号、地址等信息；
  - 手机号/证件号会**加密存储**，列表中自动**脱敏**显示（如 `138****1234`）；
  - 仅超级管理员可查看明文（客户详情页内）。
- **查看详情**：点击客户行查看完整档案。

### 3.3 订单管理（核心模块）

路径：**订单管理 → 订单列表 / 创建订单**

#### 订单状态说明

| 状态 | 含义 |
|---|---|
| 已创建（CREATED） | 客服已提交，待审核 |
| 已审核（AUDITED） | 审核通过，待派单 |
| 已驳回（REJECTED） | 审核未通过，客服可修改重提 |
| 待派单（WAIT_DISPATCH） | 即将进入派单流程 |
| 已派单（DISPATCHED） | 系统/调度员已分派装维 |
| 安装中（INSTALLING） | 装维开始施工 |
| 已完成（FINISHED） | 施工完成、网络已开通 |
| 已关闭（CLOSED） | 订单终态 |
| 已取消（CANCELLED） | 订单终态 |

#### ① 创建订单（客服）

1. 进入 **订单管理 → 创建订单**；
2. **选择客户**：已有客户直接搜索选择；新客户选择"新客户"并填写姓名/手机号/证件号；
3. **选择套餐**：100M / 300M / 500M / 1000M（价格随套餐显示）；
4. **填写安装地址**，点击【资源核查】：
   - ✅ **可安装**：该地址在资源台账内且未安装，可正常下单；
   - ⚠️ **资源不足**：房间已安装或无此房号，建议联系客户更换地址；
   - ❌ **暂无覆盖**：地址不在资源台账内，建议登记覆盖需求；
   - 核查结果会**自动写入订单**，全程留痕；
5. （可选）地图选点定位、填写预约时间、备注；
6. 点击【提交】。

#### ② 订单审核（审核员）

1. 进入 **订单列表**，找到状态为"已创建"的订单；
2. 点击右侧【审核】按钮（或进入订单详情）；
3. 查看订单摘要（客户、套餐、地址、预约时间、备注）；
4. 选择"**通过**"或"**驳回**"，可填写审核备注；
5. 点击【确认】。

> - **审核通过**后，系统会**自动触发智能派单**（见 3.4）；
> - **审核驳回**后，订单进入"已驳回"状态，**不会作废**——客服可在订单详情中修改信息后**重新提交**，重新走审核流程。

#### ③ 驳回后修改重提（客服）

1. 在订单列表中找到"已驳回"状态的订单；
2. 进入**订单详情**，查看驳回备注（审核意见）；
3. 修改相关信息，点击【重新提交】；
4. 订单重新进入"已创建"，等待再次审核。

#### ④ 查看订单详情与时间线

进入任一订单的详情页，可查看：

- 订单完整信息（客户、套餐、地址、受理人、审核人、各环节时间）；
- **订单时间线**：从创建→审核→派单→施工→开通的每一步留痕记录，谁在什么时间做了什么操作一目了然。

### 3.4 工单与派单（调度员核心）

路径：**工单管理 → 派单工作台 / 工单列表**

#### 派单工作台

- 顶部统计卡：**待派单 / 已派单 / 施工中 / 已完成**数量；
- **待处理订单**列表：列出所有待派单订单，点击订单卡片弹出派单面板；
- 自动每 30 秒刷新，也可点【刷新】手动刷新。

#### 派单方式

| 方式 | 说明 |
|---|---|
| **智能自动派单** | 点击【自动派单】，系统按评分算法推荐最优装维并派单（审核通过后也会自动触发） |
| **手动派单** | 弹窗中查看系统推荐的**候选装维列表**（含评分/距离/负载/技能/评分维度），点击某位装维完成手动派单 |

**派单评分依据**：距离(40%) + 负载(25%) + 技能匹配(20%) + 历史评分(15%)，系统自动计算谁最合适。

#### 工单状态

待派发 → 已派发 → 已接单 → 施工中 → 已完成；异常时可转单/失败重派。

#### 改派

对已派出的工单，在**工单列表/详情**中可执行【改派】：系统会取消原指派并重新挑选装维（30 分钟冷却期内不可重复改派，防止频繁操作）。

### 3.5 装维管理

路径：**装维管理 → 装维列表 / 装维地图**

- **装维列表**：查看装维档案（技能、服务区域、工作量、评分）；
- **装维地图**：地图上查看在线装维的位置分布；
- 装维的在线状态（上有工/下班打卡）会同步至此，供派单参考。

### 3.6 资源管理（网络资源台账）

路径：**资源管理 → 网络资源台账**

用于维护"地址 + 网络设备"两级台账，是下单资源核查的数据来源。

#### 地址台账（区域 → 小区 → 楼栋 → 单元 → 房间）

1. 按"区域 → 小区 → 楼栋 → 单元"逐级选择，右侧显示该单元下**房间列表**及状态（空闲/已安装）；
2. 点击【新增】可添加区域、小区（名称+地址）、楼栋（名称+总层数）、单元、房间（房号）。

#### 设备台账（OLT → PON → ONU）

1. 按"OLT → PON 口"逐级选择，右侧显示该 PON 口下的 **ONU（光猫）列表**及占用情况；
2. 点击【新增】可添加 OLT（名称/IP/厂商/型号）、PON 口（端口数）、ONU（SN/型号）。

> 资源台账完善程度直接决定下单地址核查的准确率，建议管理员及时维护。

### 3.7 系统管理（仅超级管理员）

路径：**系统管理 → 用户 / 角色 / 菜单 / 部门**

| 功能 | 说明 |
|---|---|
| 用户管理 | 新增/停用用户、分配角色、重置密码 |
| 角色管理 | 维护角色及其权限（勾选角色可访问的菜单/按钮权限） |
| 菜单管理 | 维护系统菜单与权限点（目录/菜单/按钮三级） |
| 部门管理 | 维护组织架构树（支持数据权限按部门隔离） |

> **数据权限提醒**：系统支持按部门隔离数据——调度员默认只看本部门数据，总部角色可看全部，管理员可看本部门及下属部门。

### 3.8 通知管理

路径：**通知管理 → 消息模板 / 消息记录**

- **消息模板**：维护短信/微信消息模板（业务触发通知时使用）；
- **消息记录**：查看所有通知的发送状态（成功/失败）。

### 3.9 日志管理（超级管理员 / 审核员）

路径：**日志管理 → 操作日志 / 登录日志**

- **操作日志**：谁在什么时间操作了什么功能（含耗时、结果、IP）；
- **登录日志**：所有登录成功/失败记录，方便安全审计。

### 3.10 考勤管理

路径：**考勤管理 → 团队报表**

- 查看装维团队上下班打卡汇总报表（按时间范围筛选）。

### 3.11 请假管理

路径：**请假管理 → 请假审批**

| 页签 | 说明 |
|---|---|
| 待我审批 | 当前待自己审批的请假单，可【同意/拒绝】并填写意见 |
| 团队日历 | 按时间段查询团队成员请假分布 |

> 请假按级别分层审批（L1/L2），装维人员请假会从"可派单人员池"中排除，避免派单给请假中的同事。

### 3.12 SLA 监控（工单时效）

路径：**SLA 监控 → 工单时效**

- 展示即将超时/已超时的工单预警，帮助调度员优先处理时效紧张的工单。

### 3.13 文件管理

路径：**文件管理**

- 查看系统内上传的所有文件（装机照片、签名等），支持按业务类型/单据筛选。

### 3.14 个人中心

- 查看个人信息、**修改密码**。

## 四、装维端（H5）使用指南

> 装维工程师使用手机浏览器打开装维端地址，登录后即可使用。所有操作均可在手机上完成。

### 4.1 登录与首页

- 使用装维账号（如 `install1`）登录；
- 首页底部有三个主入口：**工单 / 我的**。

### 4.2 我的工单

路径：**首页 → 工单**

工单列表分三个页签：

| 页签 | 内容 |
|---|---|
| **待接单** | 派给本人工单，需及时【接单】 |
| **进行中** | 已接单/施工中工单，可进入装机流程 |
| **已完成** | 历史完工工单 |

**接单**：在待接单列表点击【接单】确认接受任务。

### 4.3 工单详情与导航

- 点击任一工单进入详情：客户地址、联系方式（脱敏）、套餐、预约时间；
- 提供**地图导航**，一键呼起手机地图前往客户地址。

### 4.4 五步装机流程（重点）

进入进行中工单，点击【开始装机】，按步骤完成：

```
① 到达现场 → ② 装机信息 → ③ 现场照片 → ④ 客户签名 → ⑤ 提交完工
```

| 步骤 | 操作说明 |
|---|---|
| **① 到达现场** | 到达客户地址后，点击【刷新位置】获取定位，点击【确认到达现场】打卡记录到达时间 |
| **② 装机信息** | 填写设备信息：**ONU MAC**（光猫MAC，格式如 `AA:BB:CC:DD:EE:FF`）、**ONU SN**（设备序列号）、**OLT 端口**（如 `0/1/3`）、**收光功率**（dBm），点【下一步】 |
| **③ 现场照片** | 点击【拍照】上传现场照片，**至少 3 张**（满 3 张后按钮才可点击下一步） |
| **④ 客户签名** | 输入客户姓名，在签名板上请客户**手写签名**，点击【保存签名并下一步】 |
| **⑤ 提交完工** | 核对完工摘要（设备信息/照片数/签名状态），可填备注，点击【提交完工】 |

**提交完工后系统自动完成**：网络开通（对 BSS 计费系统）→ 订单标记完成 → 发送完工通知给客户。

> 提示：
> - 每步都实时保存，中途退出可继续；
> - 施工中如遇问题（如设备异常）可联系调度员转单/改派。

### 4.5 考勤打卡

路径：**我的 → 考勤打卡**

- 每天上下班各打一次卡：
  - 上班到达后点击【上班打卡】记录到岗；
  - 下班时点击【下班打卡】记录离岗；
- **考勤历史**：查看自己的打卡记录；
- 打卡状态实时同步，供调度员决定能否派单。

### 4.6 请假申请

路径：**我的 → 申请请假**

1. 选择**请假类型**（事假/病假/年假等）；
2. 填写开始/结束时间、时长、请假原因；
3. 提交后由对应负责人（L1/L2）逐级审批；
4. **我的请假**：查看申请记录与审批状态。

### 4.7 个人中心

- 查看本人工单统计（待接/进行中/已完成数量）；
- 上下班状态切换；
- 修改个人资料。

## 五、核心业务流程走查

以一个完整业务为例，展示全链路协同：

```
① 客户报装
   客服在管理后台【创建订单】，填写客户+套餐+地址，点击【资源核查】确认可安装
       │
② 客服审核（系统自动）
   订单进入"已创建"，同时系统按评分算法自动匹配装维
       │
③ 审核员审核
   审核通过 → 订单进入"待派单"；自动触发智能派单
   审核驳回 → 客服修改后重新提交
       │
④ 调度员确认/手动干预
   派单成功 → 生成工单，发送短信通知装维
   派单失败 → 调度员在【派单工作台】手动选择装维
       │
⑤ 装维上门施工（H5）
   接单 → 到达打卡 → 录入设备信息 → 拍照（≥3张）→ 客户签名 → 提交完工
       │
⑥ 系统自动开通
   BSS 开通网络 → 订单标记"已完成" → 客户收到完工通知
       │
⑦ 订单归档
   全程时间线留痕，管理员可在看板/日志中追溯
```

**争议场景处理**：

| 场景 | 处理方式 |
|---|---|
| 地址核查显示"暂无覆盖" | 客服联系客户说明，登记覆盖需求或更换地址 |
| 地址核查显示"资源不足" | 房间已被安装/无此房号，建议更换地址 |
| 工单长期无人接单 | 调度员手动派单或改派其他装维 |
| 装维施工中设备故障 | 装维联系调度员转单，工单重新进入派发池 |
| BSS 开通失败 | 系统自动回滚工单状态，装维可重新提交完工 |

## 六、常见问题 FAQ

**Q1：登录提示验证码错误？**
A：点击验证码图片刷新重试；验证码 5 分钟有效，过时请刷新。

**Q2：登录后看不到某些菜单？**
A：菜单按角色权限显示。若职责需要，请联系管理员在【系统管理 → 角色管理】中为该角色勾选对应权限。

**Q3：创建订单时提示"暂无覆盖/资源不足"怎么办？**
A：说明该地址未纳入资源台账或房间不可安装，请联系管理员维护【资源管理】台账，或更换客户地址后再下单。

**Q4：订单被驳回后怎么处理？**
A：查看详情中的驳回备注，修改信息后点击【重新提交】即可，无需重新建单。

**Q5：装维在 H5 端无法获取定位？**
A：确认手机已开启定位权限，并允许浏览器使用位置信息；在页面点击【刷新位置】重试。

**Q6：现场照片上传失败？**
A：检查网络；单张照片大小有限制（≤20MB）；可重新拍照上传，已上传的会保留。

**Q7：提交完工后提示开通失败？**
A：系统已自动把工单回滚为"施工中"，工单数据不会丢失，请检查设备信息后重新提交完工。

**Q8：如何查看哪些操作是谁做的？**
A：管理员/审核员可在【日志管理】查看操作日志（含操作人、时间、内容、IP）。

**Q9：忘记密码？**
A：请联系管理员在【系统管理 → 用户管理】中重置密码；也可登录后到【个人中心】修改。

## 七、附录：系统运行说明

> 以下内容供运维/部署人员参考，普通用户无需操作。

### 7.1 运行环境

| 组件 | 说明 |
|---|---|
| 后端 | Java 21 + Spring Boot 3.2.5，端口 8080 |
| 前端管理后台 | Vue 3 + Vite 5，端口 5173 |
| 装维端 H5 | Vue 3 + Vant 4，端口 9002 |
| 数据库 | MySQL 8（库名 `bbpms`） |
| 缓存 | Redis 7 |

### 7.2 启动步骤

```bash
# 1. 启动中间件（MySQL + Redis，docker 方式）
docker compose up -d

# 2. 启动后端（bbpms-parent 下）
mvn -pl bbpms-app spring-boot:run

# 3. 启动管理后台
cd bbpms-admin-web && npm run dev        # http://localhost:5173

# 4. 启动装维端
cd bbpms-installer-h5 && npm run dev     # http://localhost:9002
```

### 7.3 数据初始化

首次启动会自动执行数据库初始化脚本（建库、建表、演示种子数据）。如需重置演示数据：

```bash
docker compose down -v && docker compose up -d
```
